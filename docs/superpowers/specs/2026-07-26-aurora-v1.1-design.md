# Aurora v1.1: Design

**Date:** 2026-07-26
**Status:** Approved by Jon (widget picks + all four carried-over infrastructure items)

## Scope (eight items)

| # | Item | Summary |
|---|------|---------|
| 1 | Bookmark folders bar | Polished successor to Tide's bookmarks bar: top-center row of folder chips read live from Chrome's Bookmarks Bar (`bookmarks` permission, read-only). Folder chip → popover (palette-style near-opaque surface) listing children with local `_favicon` icons; subfolders drill in with a back row; loose bookmarks render as plain chips; overflow beyond the row collapses into a `»` chip. Toggleable widget (`settings.widgets.bookmarks`). |
| 2 | Notes scratchpad | "Notes" pill bottom-left mirroring the Tasks pill; lazy panel with ONE autosaving scratchpad (debounced writes to `notes`, cross-tab sync via storage events). Deliberately not a multi-note app. Toggleable (`settings.widgets.notes`). |
| 3 | World clocks | Up to 4 zones as a quiet centered row under the main clock ("Tokyo 9:41 AM"), per-zone label + `Intl` formatting; configured in Settings via searchable IANA zone picker (`Intl.supportedValuesOf('timeZone')`). Toggleable (`settings.widgets.clocks`). |
| 4 | Countdown | Events (name + date) in Settings; nearest upcoming renders as one line under the greeting ("14 days to launch"; "Launch is today."). Past events auto-hide. Toggleable (`settings.widgets.countdown`). |
| 5 | Weather details | Expanded panel gains a details row: feels-like, wind (km/h / mph by units), humidity, sunrise/sunset. Adds `daily=sunrise,sunset` to the existing Open-Meteo call; snapshot fields optional so old caches stay valid. |
| 6 | Multi-photo backgrounds | IndexedDB single upload slot becomes a gallery: multi-file add, thumbnail grid with per-photo delete in Settings → Background, daily rotation + ↻ across the user set when source = "My photos". Existing single upload migrates in lazily. |
| 7 | Export / import backup | Settings → Data: Export downloads `aurora-backup-YYYY-MM-DD.json` (all storage keys + schema version; uploaded photos excluded — noted in UI). Import validates shape + version, runs `migrate()`, and requires an explicit confirm before overwriting. |
| 8 | Polish batch | (a) Shared dialog stack — Escape closes the NEWEST open dialog first (replaces the first-consumer convention in Drawer/TodoPanel/TimerWidget/Palette); (b) weather + timer controls join the tab order after the gear deliberately (documented) or earlier if trivial; (c) weather re-checks staleness on `visibilitychange`; (d) ArrowUp/Down aliases in the theme radiogroup. |

Also: private GitHub repo `jcooler/aurora-newtab` created and `main` pushed (done at design time); version bumps to 1.1.0 at the end; README gains sections for every new feature and the `bookmarks` permission is added to the privacy statement (read locally, never transmitted).

## Schema v2 — the first real migration

New top-level keys: `notes: { text: string; updatedAt: number }`, `worldClocks: { zone: string; label: string }[]`, `countdowns: { id: string; name: string; date: string }[]`.
New NESTED keys: `settings.widgets` gains `bookmarks`, `notes`, `clocks`, `countdown` (defaults: bookmarks false, notes true, clocks false, countdown false).
Nested additions are exactly what the default-merge does NOT cover, so `CURRENT_VERSION` bumps to **2** with `migrations[1]` backfilling the new widget toggles (and tolerating partial snapshots). `WeatherSnapshot` gains optional `sunriseISO`/`sunsetISO`/`windUnit`-free fields — optional ⇒ no migration needed for caches.

## Explicitly rejected (unchanged ethos)

RSS/news, stocks, email, account-based calendar, top-sites (offered, not picked), mini calendar (not picked), habit streaks (not picked), pomodoro count + quote favorites (not picked — remain backlog).

## Verification standard

Same as v1: TDD for pure logic (bookmark tree transform, countdown phrasing, migration, export/import round-trip, gallery rotation), subagent-per-task with independent review, Playwright preview screenshot per visual change reviewed by the controller, no console errors end-to-end.
