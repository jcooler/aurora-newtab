# W3-SP1: Connectors Drawer Rework Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Connectors tab becomes a searchable, categorized catalog — a fixed search field over a scrollable card region, category groups with quiet eyebrows, and connected/enabled cards pinned to an "On your board" group — with every card body, connect flow, and permission mechanic byte-identical.

**Architecture:** `ConnectorDescriptor` gains a `category` field (the registry stays the single source of truth for naming AND grouping). The Connectors tab restructures from a flat `Section` into a full-height flex column: search input fixed at top, card list in its own `overflow-y-auto` region below (the Drawer's own scroll is bypassed for this tab — ONE visible scrollbar, no nested-scroll jank). Search filters via the existing `fuzzyScore` (src/lib/fuzzy.ts) over label + blurb; an active query flattens grouping to a ranked result list.

**Tech Stack:** unchanged (React 19, TS strict, Tailwind 4, Vitest, Playwright preview harness). No new deps. No schema change (categories are descriptor data, not stored config).

**Spec:** `docs/superpowers/specs/2026-08-10-wave3-design.md` (W3-SP1 section — binding, including the popularity ruling: category grouping IS the "sort by purpose"; no fake ranking).

```tsx
export default function Connectors({ connectors, storage }: { … }) {
  const [query, setQuery] = useState('')
  const q = query.trim()

  // Grouping is DERIVED per render from the registry + live config — no
  // memo: seven descriptors is nothing, and staleness bugs cost more than
  // the map does.
  const enabled = (d: ConnectorDescriptor) => !!connectors?.[d.id]?.enabled
  const results = q
    ? CONNECTORS.map((d, i) => ({ d, i, score: fuzzyScore(q, `${d.label} ${d.blurb}`) }))
        .filter((r): r is { d: ConnectorDescriptor; i: number; score: number } => r.score !== null)
        .sort((a, b) => b.score - a.score || a.i - b.i)
        .map((r) => r.d)
    : null
  const pinned = q ? [] : CONNECTORS.filter(enabled)
  const grouped = q
    ? []
    : CATEGORY_ORDER.map((cat) => ({
        cat,
        cards: CONNECTORS.filter((d) => d.category === cat && !enabled(d)),
      })).filter((g) => g.cards.length > 0)
  …
}
```
